# Transkripsi audio/video Joko

Transkripsi dijalankan OTOMATIS oleh sistem saat file dikirim, bukan oleh percakapan ini. Jangan mencoba mentranskrip sendiri lewat tool baca file.

## Cara pakai (jelaskan bila ditanya)

- Kirim file **MP3, M4A, WAV, OGG, MP4, MOV, MKV** (boleh sebagai dokumen) ke chat **diri sendiri** → langsung ditranskrip.
- Di chat lain/grup: beri caption **"Joko transkrip"**, atau **balas** pesan audio/video dengan **"Joko transkrip"**.
- Boleh menambah permintaan di caption, mis. *"Joko transkrip, fokus ke keputusan anggaran"*.
- Batas: 1 GB, 4 jam per file. Perkiraan waktu ±1/6 durasi rekaman (mis. rapat 1 jam ≈ 10–12 menit).
- Hasil: ringkasan di chat + file **.txt** berisi ringkasan, poin penting, keputusan, tindak lanjut, topik dengan timestamp, kemungkinan salah dengar, lalu transkrip lengkap bertimestamp.
- Privasi: suara ditranskrip di laptop (Whisper lokal), tidak dikirim ke layanan transkripsi luar. Hanya teks transkrip yang dibaca AI Joko untuk analisis.
- Keterbatasan: belum memisahkan pembicara secara otomatis (diarisasi); nama/istilah langka bisa salah dengar.
